## 4. Gói deploy bản xem trước
Tạo `scripts/pack_deploy.py`, chỉ dùng thư viện chuẩn Python:
- Xoá rồi tạo lại `deploy/ecobit-hub/`. Chép **theo danh sách cho phép**:
  - `index.html`, `netlify.toml`, `src/`, `public/`;
  - các file gốc dạng `*.ico`, `*.webmanifest`, `robots.txt` nếu có.
  - Không chép `raw/`, `docs/`, `scripts/`, `qa-shots/`, `.claude/`, `.git*`, `CLAUDE.md`, `README.md`, `package.json`, `__pycache__`.
- Cờ `--preview` (mặc định bật; `--release` thì tắt): chèn `<meta name="robots" content="noindex, nofollow">` vào `deploy/ecobit-hub/index.html` (chỉ bản chép, không sửa `index.html` gốc) và tạo `robots.txt` chặn toàn bộ.
- Nén thành `deploy/ecobit-hub.zip`. In ra số file, tổng dung lượng và 5 file lớn nhất.
- Tự kiểm sau khi đóng gói:
  - trong gói không có đường dẫn nào chứa `raw/`, `docs/`, `scripts/`, `qa-shots`;
  - mọi `ui.img(...)` và `import` trỏ tới file có thật trong gói. Quét `src/` để lấy tên ảnh và đối chiếu với `public/img/`.
- Thêm `deploy/` vào `.gitignore`.

`scripts/qa_common.py`: cho phép đặt `QA_ROOT` (biến môi trường) để server phục vụ thư mục khác. Mặc định vẫn là gốc repo.
Chạy thử trên gói: `QA_ROOT=deploy/ecobit-hub python3 scripts/qa_screens.py` với vài route đại diện (home, discover, play/quiz, journey, lab/recycle, passport/card, connect). Kết quả phải: 0 lỗi console, 0 lỗi 404.

`docs/DEPLOY.md`, mục Netlify:

- Ghi chú: bản phát hành chính thức (sau M8) chạy với `--release`, và nhớ điền `publicUrl`.
